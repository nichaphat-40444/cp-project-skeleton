# copilot — ใช้ GitHub Copilot ในโปรเจกต์นี้อย่างไร

Copilot อยู่ใน VS Code แล้ว (ไม่ต้องติดตั้ง) — ลงชื่อเข้า GitHub แล้วเปิด Chat (Ctrl+Alt+I หรือไอคอนด้านบน) ใช้ **Ask mode**

## Copilot ใน repo นี้ถูกตั้งค่าไว้แล้ว
- อ่าน `.github/copilot-instructions.md` อัตโนมัติ → มันรู้โครงสร้างโปรเจกต์ กติกา และจะทำตัวเป็น **ติวเตอร์** (ให้คำใบ้ก่อน ไม่เขียนทั้งหน้าให้)
- เปิดไฟล์ใน `pages/`, `templates/`, `models.py` → มีกฎเพิ่มเฉพาะไฟล์นั้น
- พิมพ์ `/` ใน Chat จะเห็นคำสั่งสำเร็จรูป 3 ตัว:

| คำสั่ง | ใช้เมื่อ |
|---|---|
| `/new-page` | จะเริ่มหน้าใหม่ — มันช่วยเลือกแบบจาก catalog แล้วบอกว่าต้องแก้บรรทัดไหน |
| `/explain-error` | หน้าขึ้น "ยังไม่พร้อม" หรือ terminal มี error — วาง error ต่อท้าย |
| `/check-my-page` | หน้าทำงานแล้ว อยากให้รีวิวก่อน commit |

## ถามให้ได้ประโยชน์
- ❌ "เขียน page2 ให้หน่อย" — ได้โค้ดที่อธิบายไม่ได้ ตอนนำเสนอจะเงียบ
- ✓ "อธิบายว่า loop ใน catalog/stats/page.py ทำอะไรทีละบรรทัด"
- ✓ "ทำไม `form["qty"]` ถึงเป็น string ทั้งที่กรอกตัวเลข"
- ✓ "ให้คำใบ้ ยังไม่ต้องบอกเฉลย"
- เลือกโค้ดแล้วคลิกขวา → Copilot → Explain ก็ได้

## มันจะปฏิเสธ (ตั้งใจ)
แก้ `app.py`, `storage.py`, `base.html`, `check_project.py` · ใช้ของยากเกินปี 1 (comprehension, lambda, dataclass, JavaScript) โดยไม่จำเป็น · เขียนหน้า n+1 ทั้งที่หน้า n ยังพัง

## กติกาเดียว
ใช้ได้ทุกที่ ทุกเวลา — **แต่ทุกบรรทัดที่ commit ต้องอธิบายได้** ถ้าอธิบายไม่ได้ ให้ถาม Copilot จนอธิบายได้ ค่อย commit
