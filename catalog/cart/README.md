# cart — เลือกของ + สรุปราคา (สถานะข้ามหน้า)

**แสดง:** การ์ดสินค้าพร้อมปุ่มหยิบ/เอาออก (ซ้าย) และแผงสรุปราคา จำนวน ส่วนลด ยอดสุทธิ (ขวา)
**พื้นฐานที่ได้ใช้:** loop (นับ/รวม), if (หยิบแล้วหรือยัง, กฎส่วนลด), function (`discount_for`)
เหมาะกับ: ร้านค้า, เลือกวิชา, จองอุปกรณ์, เลือกตัวจริงในทีม — อะไรก็ตามที่ "ติ๊กเลือกแล้วไปดูสรุป"

**ตะกร้าอยู่ที่ไหน — สำคัญ**
ใน `data.json` เป็น field `"picked": true/false` ของแต่ละแถว
ตัวแปรบนหัวไฟล์ (`cart = []`) **ใช้ไม่ได้** เพราะ app.py โหลดไฟล์หน้าใหม่ทุกครั้งที่กด → ค่าหายหมด
data.json คือความจำเดียวที่มี (ตะกร้าเดียวสำหรับทุกคนที่เปิดเว็บ — พอสำหรับโปรเจกต์วิชานี้)

**กลไก:** ทุกปุ่มเป็นฟอร์ม POST เล็ก ๆ ส่ง `action` (add / remove / clear) + `no` (ตำแหน่งแถว) มาที่ `handle` เดียว
หลัง POST app.py จะพากลับมาหน้าเดิม (รวม `?q=` ถ้ามี) พร้อมแถบเหลือง

**หมายเหตุ:** ตัวอย่างนี้คิดจำนวนจาก field `qty` — ถ้าข้อมูลของกลุ่มไม่มี qty (ของมือสองชิ้นเดียว) ให้นับ 1 ต่อแถว: `count = count + 1`

**ปรับให้เป็นของกลุ่ม**
- เปลี่ยนกฎใน `discount_for()` — หรือเปลี่ยนเป็นค่าส่ง, ภาษี, โควตา
- ถ้าอยากให้ "หยิบ" อยู่อีกหน้า (เช่น หน้า list) ก็คัดลอกฟอร์มเล็ก ๆ กับส่วน `add/remove` ของ `handle` ไปไว้ที่หน้านั้น
- รูป: ใส่ field `"image": "mouse.svg"` ในแถว แล้ววางไฟล์ใน `static/img/` (มีไอคอนตัวอย่าง 13 ไฟล์ให้แล้ว)
