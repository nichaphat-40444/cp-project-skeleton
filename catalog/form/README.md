# form — ฟอร์มเพิ่มรายการ + ตรวจข้อมูล + ปุ่มลบ

**แสดง:** ฟอร์ม 4 ช่อง (ซ้าย) และตารางทุกรายการพร้อมปุ่มลบ (ขวา); กรอกผิดจะขึ้นแถบเหลืองบอกเหตุผล
**พื้นฐานที่ได้ใช้:** function (`check`, `read_number`, `handle`), if/else (ตรวจแต่ละช่อง), list (`append`, `pop`)

**กลไก**
- `<form method="post">` → app.py เรียก `handle(form)` → `form` เป็น dict ที่ key = `name="..."` ของแต่ละช่อง
- `handle` return ข้อความ → ขึ้นเป็นแถบเหลืองด้านบน
- หน้านี้มี **2 ฟอร์ม** ส่งมาที่ `handle` เดียวกัน: ฟอร์มเพิ่ม กับฟอร์มลบเล็ก ๆ ต่อแถว (`<input type="hidden" name="delete">`)
  `handle` แยกด้วย `if "delete" in form:` — นี่คือแบบแผนเวลามีหลายปุ่มในหน้าเดียว
- ปุ่มลบส่ง `item.no` ที่ `build()` ประทับไว้ (= ตำแหน่งจริงใน list) **ไม่ใช่ `loop.index0`** เพราะตารางแสดงกลับด้าน (`|reverse`) — ถ้าใช้ loop.index0 จะลบผิดแถว

**กับดักที่พบบ่อย**
- ช่องที่ไม่ได้ติ๊ก (radio/checkbox) หรือ input ที่ `disabled` จะ **ไม่ถูกส่งมา** → `form["x"]` พัง → ใช้ `form.get("x", "")` เสมอ
- `float("nan")` ผ่าน `try/except` ได้ → `read_number()` กันไว้ให้แล้ว

**ปรับให้เป็นของกลุ่ม:** เปลี่ยนช่องในฟอร์มให้ตรง field ของกลุ่ม (ทั้ง `name="..."` ใน html และ `form["..."]` ใน py)
**ไอเดียต่อยอด:** ห้ามชื่อซ้ำ — loop ดู `items` ใน `check()`
