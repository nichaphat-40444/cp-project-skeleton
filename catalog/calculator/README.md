# calculator — ใส่ตัวเลข → loop คำนวณ → ตาราง + กราฟ

**แสดง:** ฟอร์มตัวเลข 3 ช่อง, การ์ดผลลัพธ์, กราฟแท่งแนวตั้ง, ตารางรายเดือน
**พื้นฐานที่ได้ใช้:** loop (`while month <= months`), if (จำกัดค่า, กัน nan), function (`read_number`)
เหมาะกับ: แผนการออม, ดอกเบี้ยเงินกู้, แปลงหน่วย, ประมาณค่าไฟ, การเติบโตของอะไรก็ได้

**กลไก**
- ฟอร์มใช้ `method="get"` → ค่าไปอยู่ใน URL `?monthly=1000&rate=5&months=12`
- `build(query)` (มี parameter 1 ตัว) จะได้ dict ของค่าเหล่านั้น **เป็นข้อความเสมอ** → แปลงด้วย `read_number()`
- ค่าว่าง/ขยะ → ใช้ค่าเริ่มต้น; ค่าเกิน → จำกัดแล้วส่ง `notice` — key ชื่อ `notice` ใน dict จะขึ้นเป็นแถบเหลืองอัตโนมัติ
- กราฟ: ความสูงแต่ละแท่ง = percent ของค่าสุดท้าย (class `.chart / .col` ใน style.css)

**ปรับให้เป็นของกลุ่ม**
- เปลี่ยนสูตรใน loop ให้เป็นเรื่องของกลุ่ม (เงินออม: `balance + monthly`; เงินกู้: `balance - payment + interest`)
- เปลี่ยนชื่อช่องและป้ายให้ตรง
- ค่าเริ่มต้นจาก data.json ไม่จำเป็น — จะเริ่มจาก 0 ก็ได้ แต่การเชื่อมกับข้อมูลของกลุ่มทำให้หน้านี้ "เป็นของเรา"
