# search — ช่องค้นหา → ตารางที่กรองแล้ว

**แสดง:** ช่องข้อความ กดค้นหาแล้วตารางเหลือเฉพาะแถวที่ตรง (ไม่สนตัวพิมพ์เล็กใหญ่)
**พื้นฐานที่ได้ใช้:** loop (วนทุกแถว) + if (ตรงหรือไม่)

**กลไก:** ฟอร์มใช้ `method="get"` → คำค้นไปอยู่ใน URL เป็น `?q=...` → `build(query)` อ่าน `query["q"]`

**ปรับให้เป็นของกลุ่ม**
- เปลี่ยน field ที่ค้น (`item["name"]`, `item["category"]`) เป็นของกลุ่ม
- อยากกรองตัวเลข เช่น ราคาไม่เกิน? เพิ่มช่อง `max_price` แล้วเพิ่ม `if item["price"] <= ...`

**ไอเดียต่อยอด:** ปุ่มหมวดสำเร็จรูป: `<a href="?q=tool">tool</a>`
