# gallery — รูปภาพ + คำบรรยาย + อัปโหลด

**แสดง:** ฟอร์มอัปโหลดรูป และการ์ดรูปภาพจาก `static/img/` คำบรรยายจาก data.json
**พื้นฐานที่ได้ใช้:** loop, if/else (มีรูปหรือใช้รูปสำรอง / ตรวจฟอร์ม)

**อัปโหลดทำงานอย่างไร**
- ฟอร์มต้องมี `enctype="multipart/form-data"` และ `<input type="file" name="photo">`
- app.py บันทึกไฟล์ลง `static/img/` ให้เอง (ตั้งชื่อใหม่กันซ้ำ) แล้วส่ง **ชื่อไฟล์** มาใน `form["photo"]`
- ไม่ได้เลือกไฟล์ หรือไฟล์ไม่ใช่รูป → `form["photo"]` เป็น `""` → เตือนผู้ใช้
- จำกัด 5 MB ต่อไฟล์ · รูปที่อัปโหลดจะอยู่ในโฟลเดอร์ของกลุ่ม (commit ได้ แต่อย่าใหญ่เกิน)

**รูปตัวอย่าง:** `static/img/` มีไอคอน SVG 13 ไฟล์ (arduino, book, mouse, …) ใช้ใน data.json ได้ทันที: `"image": "book.svg"`

**ปรับให้เป็นของกลุ่ม**
- เปลี่ยน `caption` เป็น field ที่อยากโชว์ใต้รูป
- ไม่ต้องการอัปโหลด? ลบ `handle()` และฟอร์มออก แล้วใส่ชื่อไฟล์ใน data.json เอง

**ไอเดียต่อยอด:** คลิกรูปไปหน้า detail: `<a href="/page2?i={{ loop.index0 }}">`
