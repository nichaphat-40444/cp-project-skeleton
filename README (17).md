# ranking — เรียงลำดับตามตัวเลข

**แสดง:** ตารางเรียงจากมากไปน้อย พร้อมเหรียญ 3 อันดับแรก
**พื้นฐานที่ได้ใช้:** loop ซ้อน (`while` ข้างนอก, `for` ข้างใน), if (เทียบค่า), list (`append`, `remove`)

ตั้งใจไม่ใช้ `sorted()` เพื่อให้เห็นว่าการเรียงลำดับทำงานอย่างไร — ถ้า Copilot เสนอ `sorted(key=...)` ถามมันว่าทำไม แล้วตัดสินใจเอง

**ปรับให้เป็นของกลุ่ม**
- เปลี่ยน `item["price"]` เป็น field ตัวเลขที่จะจัดอันดับ (goals, score, amount)
- อยากเรียงน้อยไปมาก? เปลี่ยน `>` เป็น `<`

**ไอเดียต่อยอด:** แสดงเฉพาะ top 5: `ranked[:5]`
